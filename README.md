# Data-Driven Prediction of Lithium-ion Battery Degradation from Partial Cycling Data Using Machine Learning

Project goal: Study the degradation of an 18650 lithium-ion battery (NMC811/graphite-silicon) over 400 cycles 
and compare two machine learning models to determine which best predicts maximum discharge capacity
